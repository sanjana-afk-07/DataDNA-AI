
# 🧬 DataDNA AI

AI-powered data fingerprinting platform that generates unique Data DNA for datasets, detects patterns and anomalies, and compares datasets using statistical intelligence.

## ✨ Features

- 🧬 Unique Data DNA fingerprint generation
- 📊 Statistical dataset analysis
- 🔍 Pattern detection
- 🚨 Anomaly detection
- 🔄 Dataset comparison
- 📁 CSV dataset analysis
- 🌐 Interactive data analysis interface

## 🎯 Objective

DataDNA AI helps users understand the hidden characteristics of datasets by creating a unique statistical fingerprint called Data DNA.

2. Install Dependencies
pip install -r requirements.txt
3. Run the Application
streamlit run frontend/app.py
4. Upload Dataset
Open the application in your browser, upload a CSV dataset, and click Submit to generate the Data DNA report.
